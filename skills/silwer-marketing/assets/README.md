# Silwer Brand Assets

Sem vlož brand assety, ktoré sa budú opakovane používať pri post-produkcii a pri nahrávaní do Higgsfield Multi-Reference / Soul Projects.

## Povinné súbory

| Súbor | Formát | Popis |
|---|---|---|
| `silwer-logo-white.png` | PNG, transparentné pozadie, min. 2000 px na šírku | Biele logo `Silwer.` — pre čierny pás a tmavé pozadia |
| `silwer-logo-black.png` | PNG, transparentné pozadie, min. 2000 px na šírku | Čierne logo `Silwer.` — pre svetlé/foto pozadia (používa sa zriedka) |
| `silwer-logo-white.svg` | SVG, vektor | Biele logo vo vektore — ideálne pre ostré škálovanie |
| `silwer-logo-black.svg` | SVG, vektor | Čierne logo vo vektore |

## Voliteľné súbory

| Súbor | Popis |
|---|---|
| `silwer-nepela-logo.png` | Subbrand "Edícia Nepela" |
| `silwer-50plus-badge.png` | Amber badge (ak sa rozhodneš vrátiť ku badge formátu v budúcnosti — aktuálne nepoužívame) |
| `product-mockups/` | Zložka s reálnymi produktovými obrázkami (fľaštičky, tubusy, dózy) — na upload ako Higgsfield reference |

## Použitie

- **Post-produkcia (Photoshop / Figma / Canva / Affinity):** otvor [references/post-production.md](../references/post-production.md), stiahni šablónu a logo vlož na určenú pozíciu.
- **Higgsfield Multi-Reference:** pri generovaní vizuálu nahraj `silwer-logo-white.png` ako druhú referenciu (prvá = produkt). V prompte uveď `use white "Silwer." logo from reference image 2, placed in top-[left/right] of the black band` — pozor, úspešnosť je stredná, finálne logo vždy preveruj a v prípade nepresnej sadzby prepíš v post-produkcii.
- **Higgsfield Projects / Soul:** vytvor projekt "Silwer" a pinni logo + 1–2 vzorové produkty — budú dostupné ako default referencie pre každú novú generáciu v projekte.

## Ochrana značky

Tieto súbory sú vlastníctvom Silwer / MW Promotion. Nepoužívať mimo Silwer kampaní.
