## D) Typ Kampane — Compositional Cues

### Brand (napr. "Vek nie je problém")

- Produkt dominantný v čiernom páse, **veľmi prázdna** druhá strana (minimalistické farebné pozadie alebo štrukturovaná textúra)
- Symbolika: vlnu → oblak → krajina → abstrakt
- Farebný akcent: mint alebo svetlá modrá

### Akcia — Black Friday / Výpredaje

- Tmavšie pozadie aj v scéne (nie len v páse)
- **Neón pink** akcent `#FF3AA0` — neónové osvetlenie produktu, pink glow efekt
- Dramatické osvetlenie (rim light z boku, zadu)
- Produkt môže byť **väčší než obvykle** (visual impact)

```
Silwer [product] bottle under dramatic neon pink rim lighting, subtle haze, dark background, vivid pink reflections on bottle surface, premium night-editorial look, commercial product photography.
```

### Sezónna — Vianoce

- Tub / darčekové balenie v páse
- Scéna: **teplé svetlo**, sviečka, textilný detail (vlnený sveter, sveter, knižka), borovicové konáre
- Farebný akcent: burgundy / teplá zlatá

```
Silwer [gift set] products beside glowing candle on a rustic wooden table, pine branches with cinnamon sticks, warm tungsten glow, cozy winter atmosphere, vivid warm colors.
```

### Sezónna — Leto

- Outdoor, golden hour, voda, svetlé prírodné materiály (linen, dyeva)
- Akcent: mint / teal

### Testimoniál / "Pred–Po" (napr. GLP1 21-dňový test)

- Rozdelené okno / split screen effect
- Scéna: **žena / muž v aktivite** (cvičenie, chôdza, pláž)
- Dvojica čísel (napr. "87 %") pridaná v post-produkcii (na panel alebo do červeného kruhu)
- **Nepoužívať** medicínske merania (váha, body fat analýza)

### Awareness day (hypertenzia, tabak…) — Layout A alebo C

- Symbolický surreálny objekt témy (hodvábne srdce s mašľou, zlomená cigareta z kvetov…)
- Rotovaný červený text s dátumom dňa ("17. MÁJ SVETOVÝ DEŇ HYPERTENZIE") — post-produkcia

```
Surreal [object symbolizing the health topic] crafted from [red silk / natural material], gift bow detail, on clean light grey studio background, soft even light, premium still-life advertising photography, vivid colors, one clear visual idea.
```

### Konceptuálna metafora — Layout C (vzory)

```
Red bikini and red-white striped swim shorts hanging on a clothesline with wooden pegs against a vivid blue summer sky, gentle breeze, minimal composition, empty sky space at top for headline.
```

## G) Aspect Ratio → Kompozičný Hint

| Ratio | Layout A (panel) | Layout B (kruhy) | Layout C (koncept) |
|---|---|---|---|
| **1:1** | Panel ľavá polovica, produkt v spodnej časti | Produkt v rukách v strede, kruhy v rohoch | Metafora v strede, packshot + kruh dole |
| **4:5** (IG feed) | Panel ľavý 45 %, subjekt vpravo | Torzo + produkt v strede, 4 kruhy v tretinách | Headline hore, metafora stred, packshot dole |
| **9:16** (Stories/Reels) | Panel ľavý 40 %, produkt v spodnej tretine, hore Stories UI | Produkt stred, kruhy hore/dole mimo UI zón | Metafora v celej výške, headline v strednej safe-zone |
| **1.91:1** (Meta+Google) | Panel ľavý 40–50 %, scéna/objekt vpravo | menej vhodné | Headline vľavo hore, metafora stred, packshot + kruh vpravo |
| **3:1** (Newsletter) | Panel ľavá ¼, scéna uprostred | Produkt v rukách, 2 kruhy | Zúžená metafora, packshot vpravo |

## H) Rýchla Kombinačná Logika

Pri každej variante si polož otázku:

1. **Čo za kampaň?** → vyber base scene archetype (A / B / C / D)
2. **Aká platforma?** → aspect ratio + kompozičný hint (G)
3. **Aká kamera?** → rotácia zo [visual-identity.md §3](visual-identity.md#3-camera-rotation)
4. **Aké svetlo?** → preset (F)
5. **Aký akcent?** → paleta zo [visual-identity.md §2](visual-identity.md#2-farebná-paleta)
6. **Aký layout (A/B/C)?** → prompt blok z [visual-identity.md §1](visual-identity.md); produkt kontextualizuj (suroviny z C)
