Podrobný popis

Rutín pre pružné drobné cievy

S pribúdajúcim vekom môže prirodzená elasticita ciev klesať a zásobovanie tkanív kyslíkom a živinami byť menej efektívne. Rutín je bioflavonoid známy svojou schopnosťou podporovať pevnosť a pružnosť drobných krvných ciev, znižovať ich lámavosť a prispievať k lepšiemu prekrveniu tkanív. V kombinácii s vitamínom C pôsobí synergicky, chráni bunky pred voľnými radikálmi a podporuje správnu mikrocirkuláciu.

Čo k tomu pridáva vitamín C

Vitamín C je nevyhnutný pre tvorbu kolagénu, ktorý udržiava štruktúru ciev, kostí, chrupaviek, ďasien a pokožky. Prispieva k normálnej činnosti nervovej sústavy a pomáha zmierniť únavu a vyčerpanie, čo oceníte najmä vo vyššom veku alebo pri fyzickej záťaži. Podporuje vstrebávanie železa, čím napomáha tvorbe červených krviniek a prenosu kyslíka. Zároveň pomáha obnovovať účinnú formu vitamínu E, ktorý pôsobí ako antioxidant.

Pre pocit ľahkých nôh

Rutín spolu s vitamínom C je vhodný aj pre ľudí, ktorí chcú posilniť pružnosť a odolnosť kapilár, predchádzať tvorbe modrín či pocitu ťažkých nôh.

Malé tablety na každý deň

Naše minitablety sú balené v praktickom dávkovači, ktorý jednoducho vezmete so sebou do kabelky či vrecka. Vďaka malým rozmerom sa tablety ľahko prehĺtajú a nezaťažujú tráviaci trakt. Balenie so 100 tabletami postačí na tri mesiace pravidelného užívania.
