Podrobný popis

Vitamín C a imunita

U seniorov je potreba doplnenia vitamínu C vyššia z viacerých dôvodov. Zmena metabolizmu spojená s vekom zvyčajne zníži efektívnosť vstrebávania vitamínu C a vedie tak k jeho nižšej hladine v tele.

Vitamín C pomáha posilňovať imunitný systém a zlepšuje schopnosť organizmu bojovať proti infekciám a chorobám, čo je obzvlášť dôležité, keď starneme a náš imunitný systém môže slabnúť.

Ochrana buniek

Vitamín C má antioxidačné vlastnosti, chráni bunky pred poškodením voľnými radikálmi. Tento účinok napomáha znížiť riziko chronických ochorení, ako sú srdcové choroby, rakovina a Alzheimerova choroba, ktoré sa častejšie vyskytujú u seniorov a skracujú tak obdobie zdravej dlhovekosti.

Pre pevnú pokožku

Vitamín C je nevyhnutný pre tvorbu kolagénu, ktorý je kľúčovou zložkou zdravia pokožky, ale aj kostí, zubov, chrupaviek, ďasien či ciev. S pribúdajúcim vekom sa obvykle naša pokožka stenčuje a stáva sa krehkejšou. Vitamín C napomáha udržať pokožku v zdraví a znížiť výskyt vrások a jemných liniek.

Prečo šípky

Šípky obsahujú protizápalové zlúčeniny, ktoré môžu pomôcť znížiť bolesť a stuhnutosť kĺbov, čo môže byť obzvlášť prospešné pre osoby s osteoartritídou alebo reumatoidnou artritídou, bežnejšou vo vyššom veku. Šípky zlepšujú absorpciu vitamínu C v organizme a obsahujú aj antioxidanty, ktoré chránia pokožku pred poškodením spôsobeným voľnými radikálmi.
